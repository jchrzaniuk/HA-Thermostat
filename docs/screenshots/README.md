# Ekrany panelu

Rendery z LVGL 8.4 na przykładowych danych, wykonane przez
`tools/preview/render.py` z kodu `main/display.cpp`. To nie są zdjęcia urządzenia.

- `overview.png`: wszystkie ekrany z podpisami.
- `01-heating.png` do `12-lan-setup.png`: pełny obraz 240×240.
- `*-round.png`: ten sam obraz przycięty do okrągłego wyświetlacza.

Ramka wokół ekranów w `overview.png` to dodatek graficzny, nie model obudowy.
